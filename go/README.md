# 🐹 Estudos em Go (Golang)

Bem-vindo ao meu cantinho de estudos em **Go**, a linguagem criada pelo Google que promete simplicidade, velocidade e umas dores de cabeça ocasionais (mas no bom sentido… eu acho 😅).

Este repositório é onde registro meus aprendizados, testes, experimentos e códigos que escrevo enquanto exploro o ecossistema Go. Se você também está aprendendo, sinta-se à vontade para fuçar — talvez ache algo útil… ou pelo menos divertido.

---

## 📚 O que você vai encontrar aqui

- Meus exercícios e projetos iniciais  
- Conceitos básicos (e alguns nem tão básicos assim)  
- Testes aleatórios que provavelmente só fazem sentido pra mim  
- Um pouco de caos organizado — afinal, aprender é assim mesmo!

---

## 🚀 Objetivo

Dominar o Go aos poucos, explorando desde o básico (variáveis, tipos, funções) até o avançado (goroutines, canais, interfaces, concorrência… e tudo aquilo que dá um nó na cabeça mas depois vira orgulho 😄).

---

## 💬 Sobre este repositório

Este espaço é totalmente dedicado ao aprendizado. Então espere encontrar:

- Comentários sinceros dentro dos códigos  
- Exemplos que eu mesmo vou revisitar no futuro  
- Evolução real — todo mundo começa do zero!
